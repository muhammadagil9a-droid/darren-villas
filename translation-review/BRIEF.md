# Translation review brief: PT Darren Adhi Jaya website

**Job:** proofread and improve existing website copy (not a translation from scratch).
**Languages:** Russian, Dutch, Portuguese (Brazil). Each file is about 900 English source words.
**Company:** a construction company in Bali that builds private villas and boutique resorts and supplies building materials. Clients are foreign villa owners and investors.
**Motto:** "We build villas with quality always on top."

## What to do
1. Open your language's file: `ru-review.csv`, `nl-review.csv` or `pt-review.csv`. It opens in Excel or Google Sheets.
2. Each row has the English source and the current translation.
3. If the translation is wrong or sounds unnatural, write the better version in the **Corrected** column. Leave that column empty if the translation is fine.

## Rules
- **Tone:** professional, calm and confident, like a premium architect's website. No hype or exclamation marks.
- **Keep placeholders exactly as written:** `{years}`, `{n}`, `{since}`.
- **Keep it short.** Buttons, menu items and labels have limited space, so make them no longer than the current text.
- **Address the reader:**
  - Russian: formal «Вы».
  - Dutch: "u" or "je", your choice, but use the same one everywhere.
  - Portuguese: Brazilian "você".
- **Do not translate:** brand and villa names (Darren Adhi Jaya, Coz, Nori, Mizu, The Young, Yugen, Coppa, Born to Live), place names and m².
